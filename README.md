# MINT BEAN 카페 온라인몰

커피와 여러 종류의 음료를 파는 카페 온라인몰입니다.
교수님의 쇼핑몰 프롬프트를 카페 주제로 바꿔서 만들었습니다.

- 과목: 웹프로그래밍 (한신대학교)
- 작성자: 조성웅 (AI·SW 소프트웨어학과)
- 사이트 보기: https://jsw0328.github.io/mint-bean-cafe/

## 주요 기능

- 음료 메뉴: 커피, 에이드, 스무디, 티, 시즌 한정 (옵션: 사이즈, 샷, 시럽, 얼음)
- 원두·드립백 배송 (3만원 이상 무료배송)
- 회원가입, 등급별 포인트 적립 (브론즈 1% · 실버 3% · 골드 5% · VIP 7%)
- 장바구니와 결제 (포인트 사용 가능)
- 모바일 기프티콘 결제 즉시 발급
- 히어로 이미지 슬라이드, 반응형 화면

## 구성

- `index.html` : HTML, CSS, JS를 모두 포함한 인라인 페이지
- `img/` : 사이트에 사용한 이미지 (직접 그린 SVG)

## 참고

- 결제와 회원 정보는 실습용 시연 기능이며, 실제 결제는 되지 않습니다.
- 생성형 AI(Claude)를 활용해 제작했습니다.
